# Algorithms-DataStructures-CPP

Repositorio de practica con ejercicios de C++ organizados por tema.

## Estructura actual

- `01-Basics/`: fundamentos para empezar.
- `02-Functions-Pointers/`: subprogramas, paso por valor/referencia y punteros.
- `03-Data-Structures/`: arreglos, `struct` y listas enlazadas.
- `04-File-Handling/`: ejercicios de archivos.
- `05-Exam-Practice/`: modelos, parciales y borradores.

## Detalle por carpeta

### `01-Basics`

- `Variables-Conditionals/`: variables, operadores, comparaciones y decisiones.
- `Loops/`: ejercicios con `for`, `while` y `do while`.
- `Strings/`: manejo inicial de cadenas y recorridos de texto.

### `02-Functions-Pointers`

- `Subprograms/`: funciones, procedimientos y paso de parametros.
- `Pointers/`: practica especifica de punteros.

### `03-Data-Structures`

- `Arrays/`: arreglos, vectores y recorridos.
- `Structs/`: modelado de datos con `struct`.
- `Linked-Lists/`: listas enlazadas y practicas relacionadas.

### `04-File-Handling`

- `Practice-Files/`: lectura, escritura y practicas con archivos.

### `05-Exam-Practice`

- `Models-and-Partials/`: modelos de parcial y ejercicios integradores.
- `Final-Practice/`: material de practica final.
- `Drafts/`: borradores o ejercicios pendientes.
